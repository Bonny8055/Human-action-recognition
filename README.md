**📘 README.md Human Action Recognition Using Deep Learning**

🏷️ Project Title
**Human Action Recognition Using Deep Learning**

**📖 Overview**

This project implements a deep-learning–based system for Human Action Recognition (HAR) using video frames.
The goal is to automatically classify human actions (such as walking, running, jumping, etc.) using a trained neural network.

Even though this is a small academic project, it demonstrates important concepts in computer vision, feature extraction, and sequence modeling in deep learning.
